# Kopfrechnen

Kopfrechnen practice web application that includes:

* Exercise Configuration: Toggles for Addition/Subtraction (up to 100), Single-Digit Multiplication, and Single-Digit Division, plus selectable session question counts.
* Active Exercise Screen: Large exercise display including the calculated result, a 1-to-10 second progress counter, and prominent Thumbs Up 👍 / Thumbs Down 👎 buttons.
* Auto-Timeout Handler: Automatically counts a 10-second timeout as a Thumbs Down 👎 and advances to the next question.
* Detailed Summary Screen: Displays total Thumbs Up 👍, Thumbs Down 👎, and calculates the exact Average Solution Time (Total elapsed time divided by total questions).
